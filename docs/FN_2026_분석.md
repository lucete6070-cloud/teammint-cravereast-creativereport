- [확인됨] pptx 출처 레코드(97건)는 원문 띄어쓰기와 ▶가 남아 있음. 문체·구조 통계는 pptx 기준 수치를 우선으로 봐야 함.

PDF 파싱에는 휴리스틱(제목 기준 분할, 텍스트 순서가 뒤바뀐 결론 줄을 다음 슬라이드로 이동, 이미지 속 번역 카피 제외)을 썼음. 일부 이미지 카피가 comment_lines에 섞였거나 결론 줄이 빠졌을 수 있음. 소재 슬롯 수(n_slots)는 "ROAS n%" 개수로 셌기 때문에 PDF 출처는 ±1~2개 오차가 있을 수 있음.

공통 뼈대 [확인됨]: 표지(리포트명·데이터 기준 기간·작성일·PERFORMANCE ARCHITECT) → 국가 간지 → OG(상시) 간지 → OG 코멘트 슬라이드 → OG TOP10 상세표 → PR 간지 → PR 코멘트 → PR TOP10 상세표 → BR 간지 → BR(파트너십) 슬라이드 → 다음 국가 → `E.O.D.`
