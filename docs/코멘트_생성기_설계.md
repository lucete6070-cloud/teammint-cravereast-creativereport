## 1. 결정사항 (지윤님)

| 항목 | 결정 |
|---|---|
| 구조 | PPT 업데이트 생성기(기존)와 코멘트 생성기(신규)를 분리 |
| 코멘트 생성기 형태 | Cowork 스킬. 구독 범위 안에서 실행해 API 추가 과금 없음 |
| 실행 주체 | 보조가 실행해 코멘트 초안이 들어간 PPT를 마케터에게 전달. 보조 계정으로 안 되면 마케터가 실행 |
| 마케터 역할 | 초안 검토·수정, 외부 요인 보완, 콜아웃 위치 지정 |
| 인사이트 적재 | 공통 + 국가별(ID·PH·MY·SG) 분리 |
| 원본 | 권역별 월 폴더의 FN 파일 |
| 학습 반영 실행 | FN을 마무리한 각 권역 마케터 |
| 충돌 판정 | 최신 월 근거를 따른다 (10/29 지윤님 결정). 판정은 학습 반영 때 자동으로 하고 변경내역에 남긴다. 판정자는 결과만 사후 확인 |
| 충돌 방지 장치 | 아래 5장대로 (이견 없음) |

## 2. 월간 흐름

1. 보조: 시트 체크 확정 → PPT 생성기 실행. 생성기가 슬라이드 노트에 전월 우수·저조 여부 등 근거 데이터를 적어 둔다.
2. 보조: Cowork에서 생성된 PPT를 첨부하고 코멘트 스킬 실행 → 코멘트 박스에 초안, 노트에 플래그·콜아웃 후보가 들어간 PPT를 받는다.
3. 보조 → 마케터 전달. 보조는 한국어 내용 품질을 판단하지 않는다.
4. 마케터: 노트의 플래그를 보며 검토·수정, 외부 요인 보완, 콜아웃 위치 지정.
5. 리뷰어 피드백 → FN 취합 (기존과 동일).
6. 마케터: FN 확정 후 Cowork에서 "이번 달 CR 학습 반영" 실행 → 참고 파일 갱신. 충돌 목록은 판정자에게.

## 3. 참고 파일 구성

| 파일 | 내용 | 갱신 빈도 |
|---|---|---|
| 작성 형식 | 제목 규칙, 본문 3줄 + ▶ 1줄, 어미·문체, 콜아웃 문구 길이 | 거의 없음 |
| 리뷰어 규칙 | 단정 금지, 전월 대비, 우수 대비, 반례 확인, 외부 요인 등 | 반복 피드백이 생길 때 |
| 성과 패턴 | 공통 1개 + 국가별 4개. 패턴마다 근거 월·캠페인·상태(유효/관찰 중/약화) | 매월 |
| 소재 이력 | 소재별 월간 우수·저조 기록과 당시 코멘트 문장 | 매월 |
| 변경 내역 | 언제 어떤 패턴이 왜 바뀌었는지. 되돌리기용 | 매월 |

- 패턴 단위는 국가×유형(OG/PR)×퍼널(유입/구매). 국가 간 차이는 충돌로 보지 않는다.
- 최근 6개월은 상세, 그 이전은 요약만 유지 [추정: 파일이 커지면 스킬이 앞부분을 놓칠 수 있음].
- 참고 파일은 광고주 성과가 들어가므로 git에 올리지 않는다. 시험 단계는 드라이브 `03. Creative Report/자동화 TEST` 폴더 사용, 운영 시 두 권역 마케터가 모두 볼 수 있는 폴더로 이동.

## 4. 매월 학습 반영

1. FN과 AI 초안을 비교해 사람이 고친 부분을 뽑는다. 같은 수정이 반복되면 리뷰어 규칙에 추가.
2. 이번 달 결론을 기존 성과 패턴과 대조.
   - 일치: 근거 월 추가, 패턴 강화
   - 신규: 근거가 한 달뿐이면 "관찰 중"으로 추가
   - 충돌: 최신 월 근거로 판정해 `판정결과.md`에 추가하고 변경내역에 기록. 이전 근거는 지우지 않고 "전월과 달리" 서술의 근거로 남김
3. 소재 이력에 이번 달 기록 추가.
4. 변경 내역 기록.

## 5. 충돌 방지 장치

- 초안 단계: 이번 달 데이터가 기존 패턴과 반대면 숨기지 않고 "전월과 달리 … 가능성"으로 변화를 서술하고, 노트에 "기존 패턴과 다름" 플래그.
- 참고 파일 단계: 충돌은 최신 월 기준으로 판정하고, 판정 결과가 국가 파일보다 우선한다. 최신 월 안에 양쪽 근거가 있으면 그 달 원문의 조건으로 나눈다.

## 7. 구현 순서

1. 1~9월 FN에서 코멘트 추출 → 첫 참고 파일 초안 (공통 + 국가별)
