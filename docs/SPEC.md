## 3. 시트 ↔ 장표 데이터 매핑 [확인됨: MY_OG&TEST, MY_PR&BR]

국가 탭(`{국가}_OG&TEST`, `{국가}_PR&BR`) 구조:
- 상단: 캠페인 요약 피벗 (채널/캠페인디테일/최적화옵션/캠페인 이름/지표)
- `[소재 카운팅]` 고효율 n / 저효율 n (합산 ≤5 규칙)
- 캠페인디테일 블록 반복: `캠페인디테일` → `캠페인명` → TOP10 행 + **`고효율 소재` / `저효율 소재` 체크박스(TRUE/FALSE)** + 메모(예: `> 유입 효율 우수`, `> 10만원 미만`)
- 좌측 = ATC(OG) 또는 PR, 우측 = PUR(OG) 또는 BR

| 장표 필드 | 시트 소스 | 포맷 |
|---|---|---|
| ATC KPI | 지출금액, CPA(장바구니 담기), ROAS | `지출 ₩910,734 / 장바구니 CPA ₩247 / ROAS 1225%` |
| PUR/PR KPI | 지출금액, CVR(구매), ROAS | `지출 ₩4,956,628 / 구매 CVR 6.92% / ROAS 519%` |
| BR KPI | 지출금액, CTR, CPC, 구매, ROAS | `소진량 28.5만원 / CTR 5.90% / CPC 47원` (+ `구매 248건 / ROAS 527%`) |
| 카드 라벨 | 캠페인디테일 | PR은 월 표기(`PayDay-Aug`) 필요할 때 있음 |
| TOP10 표 | 블록 TOP10 행 그대로 | 열 순서 = 시트 열 순서 |
| 표 하이라이트 | 체크박스 TRUE 행 | 고효율 연두 / 저효율 분홍 |

대조 결과: MY ATC Mask 소재 KPI 시트 = 장표 일치 (₩910,734 / ₩247 / 1225%). 숫자는 시트 값을 문자열 그대로 옮기면 되고 재계산은 필요 없음.

주의: 블록에 캠페인 없으면 `#N/A` 행 존재 → 생성기에서 스킵 처리.

## 5. 코멘트 스타일 가이드 (8월·9월 FN + 피드백본 기준)

### 5-1. 구조 [확인됨]
- 제목: `{국가} {상시/프로모션} 캠페인 {유입/구매} 효율 {우수/저조} 소재` (`<>`로 통합)
- 본문 3줄 + `▶` 제언 1줄
  1. 공통 패턴: 우수(또는 저조) 소재들의 첫 화면 구성 공통점
  2. 캠페인별 특이점 또는 전월 연속성 (`캠페인명 :` 접두 사용)
  3. 대비 해석: 저조 대비(우수 슬라이드) / 우수 대비(저조 슬라이드), 외부 요인 여부
  4. `▶` 다음 달 소재 운영 제언
- 이미지 콜아웃 태그: 6~12자 명사구 (예: `설명 요소 비중 높음`, `할인 혜택 부재`, `다량의 텍스트`, `단일가 제시 ▶ 가격 비교 과정 단순화`)

### 5-2. 문체 [확인됨]
- 개조식 명사형 종결: `~양상`, `~경향성`, `~확인`, `~기록`, `~판단`, `~사료`, `~가능성`, `~제언`, `~의견`
- 관점 어휘: 첫 화면, 가격·할인·구성, 효능·전후 비교·리뷰(설명 요소), 구매 메리트, 직관성, 시선 분산, 단일 메시지, 대표 SKU
- 수치는 문장에 최소로 (ROAS 등 1~2개)

### 5-3. 리뷰어 피드백 규칙 (혜원님 피드백본에서 추출) [확인됨]
1. **단정 금지**: 원인은 `~가능성`, `~로 사료`로
2. **전월 대비 서술**로 설득력 강화 (예: MegaSale 피크데이 소재 전월에 이어 부스팅)
3. 전월 코멘트와 **문장이 비슷해 보이지 않게**
4. 저조 분석은 소재 단독이 아니라 **우수 소재 대비 + 전월 대비**로
5. **반례 확인**: 같은 유형이 다른 캠페인에서 우수하면 그 이유만으로 단정하지 않기
6. 추상 표현 구체화 (예: "사은품 구성 부족" → 어떤 부분이 부족한지)
7. 두드러진 특징은 이미지에 **빨간 박스 표기**
8. **외부 요인** 고려 (월초 신규 SKU 출시, 피크데이, 예산 재배분, 시즌 수요)
9. 프로모션 캠페인명 월 표기 (`PayDay-Aug`), 우수 소재 선택 재검토

→ 1·2·4·5·8은 규칙으로 일부 자동화 가능 (전월 RD 매칭으로 "연속 우수/저조" 플래그, 같은 피처의 타 캠페인 성과 조회). 3·6·7은 AI 초안 + 사람 검토.

### 5-4. 코멘트 생성 입력 설계 (P2 스킬)

| 평균 대비 차이, 전월 우수/저조 여부, 동일 피처 타 캠페인 성과 | 스크립트 계산 (LLM 계산 금지) |
| 소재 시각 피처 (가격 첫 화면 노출, 텍스트 양, 제품 수, 인물/전후비교, 단일가) | 이미지 Vision 태깅 |
| 네이밍 토큰 (IMG/VID, 라인, 제품, Product/Influencer, Discount/Function/BnA…) | 규칙 파싱 (네이밍인덱스 탭 활용) |
| 전월 같은 슬라이드 코멘트 | 전월 FN에서 추출 (중복 문장 회피용) |
| 운영 히스토리 (신규 SKU, 프로모션 일정) | 마케터 메모 1~3줄 입력 |

출력: 슬라이드별 코멘트 초안(3줄 + ▶) + 콜아웃 태그 후보 + "근거 약함" 플래그 → PPT 코멘트 박스에 바로 삽입.
