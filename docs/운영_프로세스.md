### 0-1. 시트 형식 확인
- [ ] 시트 파일 제목에 데이터 기간이 `(08/24-09/20)` 형태로 있다. (CSV 로 내려받으면 `(08_24-09_20)` 으로 바뀌며, 프로그램이 이 기간을 읽어 표지에 넣는다.) [확인됨: 9월 파일]
- [ ] 국가 탭 이름이 `MY_OG&TEST`, `MY_PR&BR`, `SG_OG&TEST`, `SG_PR&BR` 처럼 `국가코드_탭이름` 이다. (ID, PH 도 같은 규칙)
- [ ] 각 블록에 `고효율 소재` / `저효율 소재` 체크박스(TRUE/FALSE)가 있고, 시트 [소재 카운팅] 규칙(합산 ≤ 5)을 따른다.

### 0-2. Meta 토큰·광고계정
- [ ] 광고계정 ID 를 **국가별로** 확인한다 (MY, SG, ID, PH). [확인됨: MY·SG]
- [ ] 장기 토큰(약 60일)을 발급한다. 권한은 `ads_read` 만. 액세스 토큰 디버거의 "Extend" 사용. [확인됨: 단기 토큰은 1~2시간 만료]
- [ ] **발급한 날짜**를 적어 둔다 (`.env` 의 `META_TOKEN_ISSUED`).
- [ ] 보조가 쓸 토큰을 어떻게 줄지 정한다: 개인 토큰을 각자 발급 / 하나를 지윤이 입력해 줌. **채팅·메일로 보내지 않는다.** (장기 해결: 광고주 BM 시스템 유저 토큰 요청 [미확인])

### 0-3. 패키지 준비
- [ ] `python tools/make_package.py` 로 `dist/creative-report-assistant.zip` 을 만든다 (광고주 데이터·토큰은 들어가지 않음). 또는 개발 쪽에서 받은 ZIP 사용.
- [ ] `GUIDE.html` (한국어·Tiếng Việt)이 ZIP 안에 있다. 베트남어는 **초안**이라 베트남 팀 검토 필요.

### 0-4. 리허설 (꼭 해 보기) [미확인]
보조에게 넘기기 전에 지윤 PC 의 **새 폴더**에서 보조와 똑같이 해 봅니다.
1. ZIP 우클릭 → 속성 → "차단 해제" → `C:\creative-report-test` 에 풀기
2. `setup.bat` 더블클릭 → 점검 통과 확인

4. 만들어진 pptx 를 PowerPoint 에서 열어 확인
5. 막히면 그 화면을 개발 쪽에 전달 → 가이드 보완 (예: 스마트 앱 컨트롤 차단 시 `python app.py` 직접 실행)

## 단계 2. 매월 작업 (보조)

기준: 데이터 마감(예: 9/20) 직후, 리포트 작성 시점(예: 9/22).

### 2-1. 시트 확정 확인 (보조 ↔ 마케터)
- [ ] 마케터가 고효율/저효율 체크를 확정했다.
- [ ] 국가별 체크 개수가 [소재 카운팅] 규칙(합산 ≤ 5)을 지킨다. (우수만 6개 이상이면 프로그램이 캠페인당 ROAS 최고 1개만 남기고 경고를 띄움)
- [ ] 카탈로그 소재(이름에 `Catalog`)는 체크해도 자동 제외된다.

### 2-2. CSV 내려받기 (담당 국가만)
- 시트의 국가 탭마다 **파일 → 다운로드 → 쉼표로 구분된 값(.csv)**. (엑셀로 받으면 수식이 깨져 `#N/A` 가 나오므로 금지)
- 담당이 MY 라면 `MY_OG&TEST`, `MY_PR&BR` 2개.
- 파일 이름에 `(08_24-09_20)` 같은 기간이 들어 있는지 확인. (시트 이름 그대로 받으면 자동)

### 2-3. input 폴더 정리
1. `C:\creative-report\input` 안의 **지난달 파일을 모두 삭제**
2. 이번 달 CSV 만 넣기
   → 지난달 파일이 섞이면 점검 단계에서 "데이터 기간이 서로 다른 CSV" 오류로 멈춘다.

### 2-4. 실행 (택1)
- **웹 화면**: `start_app.bat` 더블클릭 → 화면에서 ① 연결 확인 ② CSV 끌어놓기 ③ 담당 국가 체크 후 [생성하기] ④ 결과 내려받기 [미확인: Windows]
- **한 번에 실행**: `run_all.bat` 더블클릭
- **명령어**: `python run_all.py` (또는 `python app.py` 로 웹 화면)
  진행은 점검 → Meta 이미지 받기 → pptx/HTML 만들기 순서이며, 몇 분 걸린다. 검은 창을 닫지 않는다.

### 2-5. 결과 확인 (체크리스트)
`output` 폴더에 국가×유형별 `pptx`(편집용)와 `html`(보기용), `생성로그.txt`, `실행기록_*.txt` 가 생긴다.
- [ ] 표지의 월·데이터 기간이 맞다. (작성일은 자동으로 오늘)
- [ ] 슬라이드 순서: 표지 → 국가 간지 → 유형 간지 → 우수·저조 → TOP10 표 → EOD
- [ ] **회색 사각형(이미지 없음)** 이 없다. 있으면 `생성로그.txt` 의 "이미지 없음" 목록 확인 → 2-6
- [ ] KPI 3~5개를 시트 값과 눈으로 대조 (프로그램은 시트 문자열을 그대로 옮김)
- [ ] `생성로그.txt` 의 **경고** 확인 (예: "우수 6개 > 5: …제외")
- [ ] 영상 소재는 대표 이미지(썸네일)라 FN 의 장면과 다를 수 있음 (같은 영상이면 정상) [확인됨]
- [ ] 코멘트 박스는 **비어 있는 것이 정상**

### 2-6. 이미지 수동 교체 (필요할 때만)
- 이미지 파일 이름은 `소재명.png`. 바꿀 이미지를 같은 이름으로 `images_manual` 폴더에 넣으면 우선 사용되고 자동 수집이 덮어쓰지 않는다.
- 넣은 뒤 다시 실행.

### 2-7. 전달
- 국가별 `pptx` 를 마케터에게 전달 (코멘트·콜아웃 작성용).
- 문제가 있었으면 `실행기록_*.txt` 를 지윤에게 (토큰은 기록에 남지 않음).

### 2-8. 정리 (보안)
- 전달이 끝나면 `input`, `images`, `output` 의 파일을 **삭제**한다. (광고주 데이터는 PC 에 남기지 않는다. `.env` 는 지우지 않는다.)

## 단계 3. 코멘트 → 리뷰 → FN 취합 (사람, 기존 방식)
- 마케터: pptx 에 코멘트와 이미지 콜아웃(빨간 박스) 작성 (P2 스킬로 초안 지원 예정)
- 리뷰어: 피드백 → 반영
- FN 취합: 국가별 파일을 하나의 덱으로 합친다. 각 파일마다 표지·국가 간지·EOD 가 들어 있어 합칠 때 정리 필요. [수동]
- BR(파트너십) 슬라이드는 이번 자동화 범위 밖 [수동]

## 단계 4. 토큰 갱신 (지윤, 약 50일마다)
1. 점검 화면이 "토큰 발급 후 N일 경과" 주의를 띄우거나, `토큰 만료` 오류가 나면 갱신한다.
2. 새 장기 토큰 발급 (단계 0-2와 동일).
3. 각 보조 PC 의 `.env` 에서 `META_ACCESS_TOKEN` 과 `META_TOKEN_ISSUED` 날짜를 바꾼다 (화면 공유 또는 직접 입력). 채팅으로 보내지 않는다.
4. 보조 PC 마다 해야 하는 일이라, 인원이 늘면 시스템 유저 토큰(만료 없음) 요청을 다시 검토한다. [미확인]

## 단계 5. 프로그램 업데이트 (지윤 → 보조)
1. 개발 쪽에서 새 버전을 받는다 (실행 화면 오른쪽 위의 버전 번호로 구분).
2. `python tools/make_package.py` 로 새 ZIP 을 만든다.
3. 보조에게 전달 → 보조는 **기존 폴더의 `.env` 와 `input` 을 보존**하고 나머지를 덮어쓴다 (또는 새 폴더에 풀고 `.env` 만 복사).
4. 업데이트 후 첫 실행은 점검 화면 통과를 확인한다.

## 문제가 생겼을 때

| 증상 | 원인 → 조치 | 누가 |
|---|---|---|
| 스마트 앱 컨트롤이 .bat 차단 | ZIP "차단 해제", `Unblock-File`, 또는 `python run_all.py` 직접 실행 | 보조 |
| `python` 을 찾을 수 없음 | Python 설치 시 PATH 체크 안 함 → 재설치 | 보조 |
| 토큰 만료 / 권한 오류 | 단계 4 | 지윤 |
| "데이터 기간이 서로 다른 CSV" | input 의 지난달 파일 삭제 | 보조 |
| CSV 글자 깨짐 | 시트에서 CSV 로 다시 내려받기 (엑셀로 저장 금지) | 보조 |
| 일부 이미지 못 받음 | 광고명에 소재명이 없음 → 소재명 확인 / 이미지 수동 교체(2-6) | 보조 → 지윤 |
| 광고가 여러 개라 다른 이미지가 들어간 것 같음 | 같은 소재명이 여러 기간에 재사용됨. 보고서 기간과 겹치는 광고를 자동 선택하지만, 의심되면 지윤에게 | 지윤 |
| pptx 글자가 겹쳐 보임 | PC 에 양식 글꼴이 없을 때. 내용은 정상, html 로 확인 | 보조 |

- 프로그램 폴더를 OneDrive·바탕화면·공유 드라이브에 두기 (자동으로 클라우드에 올라감)
- 엑셀로 열어서 CSV 를 다시 저장하기
