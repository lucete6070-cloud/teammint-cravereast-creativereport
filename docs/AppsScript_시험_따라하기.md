# Apps Script 하루 시험 — 따라하기 (지윤님용)

> 작성: 2026-10-26 | 걸리는 시간: 준비 10분 + 시험 30~60분
> 코드는 한 줄도 쓰지 않습니다. 붙여넣기와 버튼 누르기만 합니다.
> 토큰은 **스크립트 속성 화면에만** 넣습니다. 채팅·문서·캡처에 절대 넣지 마세요.

## 0. 준비물 (PC 가 바뀌어 `C:\creative-report` 가 없어도 아래에서 전부 구할 수 있음)

이 시험은 PC 에 아무것도 설치하지 않습니다. 저장소를 내려받을 필요도 없습니다.

### 0-1. Meta 장기 토큰 새로 발급 (5분) [운영_프로세스 0-2 와 동일]
전에 쓰던 **지윤님 개인 Meta 계정**(광고주 광고계정 접근 권한이 있는 계정 [확인됨: SPEC 4장])으로 합니다.
1. https://developers.facebook.com/tools/explorer 접속.
2. 오른쪽 "Meta 앱" 에서 전에 만든 앱 선택 (없으면 "앱 만들기" → 유형 "기타/비즈니스" → 이름 아무거나).
3. "권한 추가" 에서 **`ads_read`** 하나만 체크 → **[Generate Access Token]** → 로그인·허용 창 → 토큰이 칸에 나타남 → 복사. (이건 1~2시간짜리 단기 토큰)
4. https://developers.facebook.com/tools/debug/accesstoken 접속 → 토큰 붙여넣기 → **[디버그]** → 맨 아래 **[액세스 토큰 연장(Extend Access Token)]** → 나오는 긴 토큰을 복사. 이것이 약 60일짜리 장기 토큰.
5. 이 값을 **2단계 스크립트 속성에만** 붙여넣습니다. 메모장·채팅·메일에 두지 않습니다. 발급일을 오늘 날짜로 적어 두세요 (60일 뒤 갱신).

### 0-2. 광고계정 ID 찾기 (2분)
1. https://adsmanager.facebook.com 접속 → 왼쪽 위 계정 선택에서 **MY** 광고계정 선택.
2. 주소창을 보면 `act=1234567890` 처럼 숫자가 있음 → 그 숫자가 ID. (`act_` 를 붙여도 되고 숫자만 넣어도 됨)
3. SG 도 같은 방법으로.
4. 또는 비즈니스 설정 → 계정 → 광고 계정 목록에서 이름 아래 ID 확인.

## 1단계. 스크립트 프로젝트 만들기 (5분)

1. 크롬에서 **https://script.google.com** 을 엽니다. (팀민트 계정인지 오른쪽 위 확인)
2. 왼쪽 위 **[+ 새 프로젝트]** 를 누릅니다.
3. 위쪽 "제목 없는 프로젝트" 를 눌러 **`Creative Report 시험`** 으로 바꿉니다.
4. 가운데 편집창에 `function myFunction() {}` 이 보입니다. **전부 지우고**, `Code.gs` 내용을 붙여넣습니다. **Ctrl+S** 로 저장.
5. 왼쪽 "파일" 옆 **[+]** → **HTML** → 이름에 **`Index`** 만 입력(확장자 없이) → Enter.
6. 새로 열린 편집창 내용을 **전부 지우고**, `Index.html` 내용을 붙여넣습니다. **Ctrl+S**.

확인: 왼쪽 파일 목록에 `Code.gs` 와 `Index.html` 두 개가 보이면 됩니다.

## 2단계. 토큰·광고계정 넣기 (3분)

1. 왼쪽 메뉴 톱니바퀴 **[프로젝트 설정]** 을 누릅니다.
2. 맨 아래 **"스크립트 속성"** → **[스크립트 속성 추가]**.
3. 아래 3개를 넣습니다. (속성 = 왼쪽 칸, 값 = 오른쪽 칸. `.env` 파일의 `=` 오른쪽 값을 그대로 복사)

| 속성 | 값 |
|---|---|
| `META_ACCESS_TOKEN` | 토큰 |
| `META_AD_ACCOUNT_ID_MY` | MY 광고계정 ID (`act_` 붙어 있어도 됨) |
| `META_AD_ACCOUNT_ID_SG` | SG 광고계정 ID |

4. **[스크립트 속성 저장]**.

> 이 화면은 캡처해서 보내지 마세요. 토큰이 보입니다.

## 3단계. 웹앱으로 올리기 (5분)

1. 오른쪽 위 파란 **[배포]** → **[새 배포]**.
2. 왼쪽 "유형 선택" 옆 **톱니바퀴** → **웹 앱**.
3. 다음과 같이 고릅니다.
   - 설명: `시험1`
   - 다음 사용자 인증 정보로 실행: **나** (본인 계정)
   - 액세스 권한이 있는 사용자: **team-mint.io 내 모든 사용자** 로 보이는 항목 (문구가 "조직 내 모든 사용자" 처럼 조금 다를 수 있습니다 [추정]. **"모든 사용자(익명 포함)"는 고르지 마세요**)
4. **[배포]**.
5. "액세스 승인" 창이 뜹니다 → **[액세스 승인]** → 계정 선택.
   - "Google에서 확인하지 않은 앱" 화면이 나오면: 본인이 방금 만든 앱이라 정상입니다. **[고급]** → 맨 아래 **[Creative Report 시험(으)로 이동]** → 요청 권한(스프레드시트 보기, 외부 서비스 연결, 이메일 주소 보기)을 **[허용]**.
6. 끝나면 **"웹 앱 URL"** 이 나옵니다. **[복사]** 해 두세요. (`https://script.google.com/a/macros/team-mint.io/s/.../exec` 모양)

> 코드를 나중에 고치면 "배포 > 배포 관리 > 연필 > 버전: 새 버전 > 배포" 를 해야 반영됩니다. 시험 중에는 **[배포] > [테스트 배포]** 의 URL(`/dev` 로 끝남)을 쓰면 저장만 해도 바로 반영돼 편합니다.

## 4단계. 시험 화면 열기 — T1 (2분)

1. 새 탭에 복사한 URL 을 붙여넣어 엽니다.
2. 맨 위 **T1** 칸에 본인 이메일이 **초록색**으로 보이면 통과.
3. **[스크립트 속성 들어 있는지 확인]** 버튼 → `META_ACCESS_TOKEN ✔`, `_MY ✔`, `_SG ✔` 3개 초록.
4. 추가 확인: 크롬 **시크릿 창**에서 개인 Gmail 로 같은 URL 을 열어 봅니다. **"권한이 없습니다"** 류의 화면이 나와야 통과. (팀민트 밖 계정이 열리면 실패 → 3단계 3번 설정을 다시 확인)

## 5단계. T2 — 시트 읽기 (2분)

1. T2 칸에 9월 시트 주소를 붙여넣고 **[읽기]**.
2. 표에 탭 4개(`MY_OG&TEST`, `MY_PR&BR`, `SG_OG&TEST`, `SG_PR&BR`)가 나오고, ₩ 칸에 `₩910,734` 같은 값, % 칸에 `6.92%` 같은 값, `TRUE`, `#N/A` 가 보이면 통과.
3. 제목 줄이 빨간색이면 시트 제목에 `(08/24-09/20)` 기간 표기가 없는 것입니다. (9월 시트는 있음 [확인됨])

## 6단계. T3 + T6 — Meta 이미지 1장 (3분)

1. 국가 **MY**, 소재명 칸에 체크된 소재명 하나를 붙여넣고 **[받아오기]**.
2. 그림이 보이고 "검색 ○ms + 다운로드 ○ms · 왕복 총 ○ms" 가 초록색이면 통과. **총 ms 숫자를 적어 두세요.**
3. 같은 방법으로 **SG** 도 한 번.

## 8단계. T5 — 이미지 크롭해 사각형 자리에 넣기 (2분)

1. T5 칸 "양식 파일" → `EAST_template.pptx`, "소재 이미지" → `images` 폴더의 아무 파일.
2. 버튼 → `T5_result.pptx` 내려받기.
