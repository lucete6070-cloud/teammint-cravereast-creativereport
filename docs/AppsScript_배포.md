# Apps Script 웹앱 배포 — 따라하기 (지윤님용)

> 작성: 2026-10-26 | 걸리는 시간: 약 20분 (시험 프로젝트를 그대로 이어 씁니다)
> 결과: 보조는 **주소 열기 → 시트 주소 붙여넣기 → 담당 국가 체크 → 생성 → pptx 내려받기**. 설치·서버·결제 없음.

## 0. 이 앱이 하는 일 (한 줄씩)
- 구글 안에서 도는 서버 코드(`Code.gs`)가 시트 국가 탭을 읽고, Meta 에서 소재 이미지를 받아 오고, 드라이브의 양식 pptx 를 넘겨 줍니다. 토큰은 스크립트 속성에만 있고 보조는 보지 못합니다.
- 보조 브라우저(`Index.html` + `plan_js` + `build_js`)가 슬라이드 계획을 세우고, 이미지를 정사각으로 잘라 양식에 넣고, pptx 를 조립해 내려줍니다. 광고주 데이터는 브라우저 메모리에만 있고 어디에도 저장하지 않습니다.
- 규칙은 파이썬 버전과 같습니다(숫자 문자열 그대로, 체크박스만, ≤5 한 장, SKU 뒤 줄바꿈, 코멘트 비움). 10월 시트 MY·SG 4개 탭으로 파이썬 결과와 **도형·글자·표 값까지 100% 일치**를 확인했습니다 [확인됨: 개발 환경].

## 1. 양식 pptx 를 드라이브에 올리기 (3분) — **선택 사항**
> 10/26 부터 양식은 코드 안에 포함됩니다(`template_js.html`). 이 단계를 건너뛰고 `TEMPLATE_FILE_ID` 를 비워 두어도 생성됩니다. 드라이브 양식은 "코드 수정 없이 양식을 바꾸고 싶을 때" 만 쓰는 덮어쓰기 수단이며, 읽기에 실패하면 자동으로 코드에 포함된 양식을 씁니다.

**어디에**: 팀민트 계정으로 로그인한 **지윤님 본인 구글 드라이브** (https://drive.google.com → 왼쪽 "내 드라이브"). 폴더는 아무 데나 괜찮고, 새 폴더 "Creative Report" 를 만들어 두면 찾기 쉽습니다. 앱이 지윤님 계정("나")으로 실행되므로 다른 사람에게 공유할 필요가 없습니다.
1. GitHub 저장소 `template/EAST_template.pptx` 를 내려받습니다 (파일 클릭 → "Download raw file").
2. 드라이브에서 **[+ 신규] → [파일 업로드]** 로 올립니다.
3. 올린 파일을 더블클릭해 열면 주소창이 `https://docs.google.com/presentation/d/파일ID/edit` 또는 `https://drive.google.com/file/d/파일ID/view` 입니다. **`/d/` 와 다음 `/` 사이의 긴 문자열이 파일 ID** 입니다. 복사해 둡니다.

## 2. 코드 5개 붙여넣기 (10분)
**어디에**: https://script.google.com → 왼쪽 **내 프로젝트** → 시험 때 만든 **"Creative Report 시험"** 클릭 → 편집기가 열립니다. 왼쪽 "파일" 목록에서 파일을 클릭하면 가운데 편집창에 내용이 나오고, 여기에 붙여넣습니다.
**어디서 가져오나**: GitHub 저장소 → 브랜치 `claude/lucid-faraday-xpneva` → `appsscript` 폴더. 각 파일을 열어 오른쪽 위 "Copy raw file" 로 복사합니다.

| 순서 | Apps Script 쪽 파일 | 붙여넣을 내용 | 만드는 법 |
|---|---|---|---|
| 1 | `Code.gs` | `appsscript/Code.gs` | 기존 내용 전부 지우고 붙여넣기 |
| 2 | `Index.html` | `appsscript/Index.html` | 기존 내용 전부 지우고 붙여넣기 |
| 3 | `plan_js.html` | `appsscript/plan_js.html` | 파일 옆 **+ → HTML** → 이름 `plan_js` → 내용 전부 지우고 붙여넣기 |
| 4 | `build_js.html` | `appsscript/build_js.html` | 같은 방법, 이름 `build_js` |
| 5 | `labels_js.html` | `appsscript/labels_js.html` | 같은 방법, 이름 `labels_js` |
| 6 | `template_js.html` | `appsscript/template_js.html` | 같은 방법, 이름 `template_js` (양식 pptx 가 글자로 들어 있어 370KB 로 큼. 붙여넣기 뒤 저장에 몇 초 걸릴 수 있음) |

각 파일마다 **Ctrl+S**. 왼쪽 파일 목록에 6개(`Code.gs`, `Index.html`, `plan_js.html`, `build_js.html`, `labels_js.html`, `template_js.html`)가 보이면 됩니다. 이름의 대소문자와 밑줄이 정확해야 합니다.

## 3. 스크립트 속성 (3분)
**어디에**: 같은 Apps Script 프로젝트 편집기에서 왼쪽 세로 메뉴의 **톱니바퀴(프로젝트 설정)** → 페이지 맨 아래 **"스크립트 속성"** → **[스크립트 속성 추가]** → 왼쪽 칸에 속성 이름, 오른쪽 칸에 값 → **[스크립트 속성 저장]**. 시험 때 넣은 3개는 그대로 두고 아래를 추가합니다.

| 속성 | 값 | 비고 |
|---|---|---|
| `META_ACCESS_TOKEN` | (시험 때 넣음) | 약 60일마다 교체 |
| `META_TOKEN_ISSUED` | 발급일 `2026-10-26` 형식 | 50일 지나면 화면에 갱신 안내가 뜸 |
| `META_AD_ACCOUNT_ID_MY`, `_SG` | (시험 때 넣음) | ID·PH 를 쓰려면 `_ID`, `_PH` 추가 |
| `META_AD_ACCOUNT_ID_ID` | `Shopee계정ID,Tokopedia계정ID` | **쉼표로 두 계정을 함께** 넣으면 두 계정 모두에서 소재를 찾습니다 (같은 소재가 양쪽에 있으면 이름 일치 > 기간 > ACTIVE 순으로 고름) |
| `TEMPLATE_FILE_ID` | (선택) 1단계의 파일 ID | 비우면 코드에 포함된 양식을 씀. 넣으면 드라이브 파일이 우선이고 실패 시 포함 양식으로 자동 대체 |

## 3-1. 권한 승인 (1분, 꼭 한 번)
드라이브·시트·외부 연결 권한은 **관리자가 편집기에서 한 번 승인**해야 웹앱이 쓸 수 있습니다. 승인 없이 배포하면 화면에 "현재 사용할 수 있는 서버가 없습니다" 오류가 납니다.
1. 편집기 위쪽 도구 모음의 **함수 선택 드롭다운**(「디버그」 옆)에서 **`authorize`** 선택 → **[실행]**.
2. "승인 필요" 창 → [권한 검토] → 계정 선택 → ("확인되지 않은 앱"이면 [고급] → [이동]) → **[허용]**.
3. 아래 "실행 로그"에 `권한 승인 완료. 양식 파일: EAST_template.pptx` 가 나오면 됩니다. 파일 이름이 다르거나 오류면 `TEMPLATE_FILE_ID` 를 다시 확인.
4. 승인 뒤에는 **4단계 새 버전 배포**를 한 번 더 합니다.

## 4. 배포 (2분)
**어디에**: 같은 편집기 **오른쪽 위 파란 [배포] 버튼**.
- 시험 배포가 있으면: **[배포] → [배포 관리] → 창 오른쪽 위 연필(수정) → "버전" 드롭다운에서 "새 버전" → [배포] → [완료]**. 주소는 그대로입니다.
- 없으면: **배포 → 새 배포 → 톱니 → 웹 앱**, 실행 "나", 액세스 "team-mint.io 사용자" → 배포 → 승인 (처음 한 번 "드라이브 파일 보기" 권한이 추가로 뜹니다 → 허용).
- 나온 **웹 앱 URL** 을 보조에게 전달합니다. 보조는 즐겨찾기에 넣어 두면 됩니다.

## 5. 첫 확인 (5분, 지윤님이 직접)
1. 주소를 열면 1번 칸에 `토큰 있음 · 계정 MY · 계정 SG · 토큰 발급일 · 양식 등록됨` 이 초록색.
2. **[연결 확인하기]** → MY·SG 광고계정 이름이 초록색.
3. 10월 시트 주소 붙여넣고 **[시트에서 가져오기]** → 탭 목록과 데이터 기간이 보임.
4. 담당 국가 MY·SG 체크 → **[생성하기]** → 이미지 진행 막대가 차고 → pptx 가 내려받아짐 (국가×유형별, 체크된 소재가 없는 탭은 "건너뜀"으로 기록).
5. PowerPoint 로 열어 표지 월·기간, 카드 라벨·KPI·소재명, 이미지, TOP10 표를 확인. "자세한 기록 보기"에서 `이미지 없음` 목록 확인.

## 6. 매월 보조가 하는 일
1. 시트 체크박스 확정 (시트 제목에 `(MM/DD-MM/DD)` 기간이 있어야 함).
2. 웹 앱 주소 열기 → 시트 주소 붙여넣기 → **[시트에서 가져오기]**.
3. 담당 국가만 체크 → 묶기 선택 → **[생성하기]** → 내려받은 pptx 를 마케터에게 전달.
   - 기본 **EAST-1(ID·PH) / EAST-2(MY·SG) 한 파일**: 표지 → ID 간지 → OG 간지 → 장표·표 → PR 간지 → 장표·표 → PH 간지 → … → EOD. 파일명 `SKIN1004_26-10_EAST-2.pptx`
   - "국가별 한 파일" `…_EAST_MY.pptx`, "OG / PR 따로" `…_EAST_MY_OG.pptx` 도 선택 가능
4. 기록의 `이미지 없음` 소재는 광고관리자에서 직접 받아 PowerPoint 에서 회색 사각형 자리에 넣습니다.
