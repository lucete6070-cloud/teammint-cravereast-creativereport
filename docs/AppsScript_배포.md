# Apps Script 웹앱 배포 — 따라하기 (지윤님용)

> 작성: 2026-10-26 | 걸리는 시간: 약 20분 (시험 프로젝트를 그대로 이어 씁니다)
> 결과: 보조는 **주소 열기 → 시트 주소 붙여넣기 → 담당 국가 체크 → 생성 → pptx 내려받기**. 설치·서버·결제 없음.

## 0. 이 앱이 하는 일 (한 줄씩)
- 구글 안에서 도는 서버 코드(`Code.gs`)가 시트 국가 탭을 읽고, Meta 에서 소재 이미지를 받아 오고, 드라이브의 양식 pptx 를 넘겨 줍니다. 토큰은 스크립트 속성에만 있고 보조는 보지 못합니다.
- 보조 브라우저(`Index.html` + `plan_js` + `build_js`)가 슬라이드 계획을 세우고, 이미지를 정사각으로 잘라 양식에 넣고, pptx 를 조립해 내려줍니다. 광고주 데이터는 브라우저 메모리에만 있고 어디에도 저장하지 않습니다.
- 규칙은 파이썬 버전과 같습니다(숫자 문자열 그대로, 체크박스만, ≤5 한 장, SKU 뒤 줄바꿈, 코멘트 비움). 10월 시트 MY·SG 4개 탭으로 파이썬 결과와 **도형·글자·표 값까지 100% 일치**를 확인했습니다 [확인됨: 개발 환경].

## 1. 양식 pptx 를 드라이브에 올리기 (3분)
1. GitHub 저장소 `template/EAST_template.pptx` 를 내려받습니다 (파일 클릭 → "Download raw file").
2. 구글 드라이브(지윤님 내 드라이브 아무 폴더)에 올립니다. 공유 설정은 바꾸지 않아도 됩니다 (앱이 "나"로 실행되므로).
3. 올린 파일을 더블클릭해 열면 주소창이 `https://docs.google.com/presentation/d/파일ID/edit` 또는 `https://drive.google.com/file/d/파일ID/view` 입니다. **`/d/` 와 다음 `/` 사이의 긴 문자열이 파일 ID** 입니다. 복사해 둡니다.

## 2. 코드 5개 붙여넣기 (10분)
시험 때 만든 프로젝트 "Creative Report 시험"을 엽니다 (script.google.com → 내 프로젝트). 새로 만들어도 됩니다.
파일은 GitHub 저장소 `appsscript/` 폴더에 있고, 각 파일을 열어 "Copy raw file" 로 복사합니다.

| 순서 | Apps Script 쪽 파일 | 붙여넣을 내용 | 만드는 법 |
|---|---|---|---|
| 1 | `Code.gs` | `appsscript/Code.gs` | 기존 내용 전부 지우고 붙여넣기 |
| 2 | `Index.html` | `appsscript/Index.html` | 기존 내용 전부 지우고 붙여넣기 |
| 3 | `plan_js.html` | `appsscript/plan_js.html` | 파일 옆 **+ → HTML** → 이름 `plan_js` → 내용 전부 지우고 붙여넣기 |
| 4 | `build_js.html` | `appsscript/build_js.html` | 같은 방법, 이름 `build_js` |
| 5 | `labels_js.html` | `appsscript/labels_js.html` | 같은 방법, 이름 `labels_js` |

각 파일마다 **Ctrl+S**. 왼쪽 파일 목록에 5개(`Code.gs`, `Index.html`, `plan_js.html`, `build_js.html`, `labels_js.html`)가 보이면 됩니다. 이름의 대소문자와 밑줄이 정확해야 합니다.

## 3. 스크립트 속성 (3분)
왼쪽 톱니 **프로젝트 설정 → 스크립트 속성**. 시험 때 넣은 3개는 그대로 두고 아래를 추가합니다.

| 속성 | 값 | 비고 |
|---|---|---|
| `META_ACCESS_TOKEN` | (시험 때 넣음) | 약 60일마다 교체 |
| `META_TOKEN_ISSUED` | 발급일 `2026-10-26` 형식 | 50일 지나면 화면에 갱신 안내가 뜸 |
| `META_AD_ACCOUNT_ID_MY`, `_SG` | (시험 때 넣음) | ID·PH 를 쓰려면 `_ID`, `_PH` 추가 |
| `TEMPLATE_FILE_ID` | 1단계의 파일 ID | 비우면 보조가 화면에서 양식 파일을 직접 골라야 함 |

## 4. 배포 (2분)
- 시험 배포가 있으면: **배포 → 배포 관리 → 연필(수정) → 버전: "새 버전" → 배포**. 주소는 그대로입니다.
- 없으면: **배포 → 새 배포 → 톱니 → 웹 앱**, 실행 "나", 액세스 "team-mint.io 사용자" → 배포 → 승인 (처음 한 번 "드라이브 파일 보기" 권한이 추가로 뜹니다 → 허용).
- 나온 **웹 앱 URL** 을 보조에게 전달합니다. 보조는 즐겨찾기에 넣어 두면 됩니다.

## 5. 첫 확인 (5분, 지윤님이 직접)
1. 주소를 열면 1번 칸에 `토큰 있음 · 계정 MY · 계정 SG · 토큰 발급일 · 양식 등록됨` 이 초록색.
2. **[연결 확인하기]** → MY·SG 광고계정 이름이 초록색.
3. 10월 시트 주소 붙여넣고 **[시트에서 가져오기]** → 탭 목록과 데이터 기간이 보임.
4. 담당 국가 MY·SG 체크 → **[생성하기]** → 이미지 진행 막대가 차고 → pptx 가 내려받아짐 (국가×유형별, 체크된 소재가 없는 탭은 "건너뜀"으로 기록).
5. PowerPoint 로 열어 표지 월·기간, 카드 라벨·KPI·소재명, 이미지, TOP10 표를 확인. "자세한 기록 보기"에서 `이미지 없음` 목록 확인.

## 6. 매월 보조가 하는 일
1. 시트 체크박스 확정 (시트 제목에 `(MM/DD-MM/DD)` 기간이 있어야 함).
2. 웹 앱 주소 열기 → 시트 주소 붙여넣기 → **[시트에서 가져오기]**.
3. 담당 국가만 체크 → **[생성하기]** → 내려받은 pptx 를 마케터에게 전달.
4. 기록의 `이미지 없음` 소재는 광고관리자에서 직접 받아 PowerPoint 에서 회색 사각형 자리에 넣습니다.

## 7. 운영 (지윤님)
| 일 | 방법 |
|---|---|
| 토큰 갱신 (약 60일) | 새 장기 토큰 발급(`docs/AppsScript_시험_따라하기.md` 0-1) → 스크립트 속성 `META_ACCESS_TOKEN` 값 교체, `META_TOKEN_ISSUED` 를 오늘 날짜로 |
| 양식 pptx 교체 | 드라이브에서 기존 파일 우클릭 → **파일 정보 → 버전 관리 → 새 버전 업로드** (파일 ID 가 유지됨). 새 파일로 올렸으면 `TEMPLATE_FILE_ID` 교체 |
| 카드·표 라벨 바꾸기 (예: PayDay-Aug) | 저장소 `config/labels.json` 수정 → `python tools/make_appsscript.py` → `labels_js.html` 다시 붙여넣기 → 배포 관리 > 새 버전 |
| 프로그램 업데이트 | 개발 쪽이 `appsscript/` 파일을 고치면 바뀐 파일만 다시 붙여넣기 → **배포 관리 > 새 버전**. 붙여넣기만 하고 새 버전을 안 만들면 반영되지 않음 |
| 국가 추가 (ID·PH) | 속성 `META_AD_ACCOUNT_ID_ID`, `_PH` 추가. 시트 탭 이름이 `ID_OG&TEST` 형식이면 자동 인식 |
| 보조 퇴사 | 워크스페이스 계정 정지로 접속 차단됨 |

## 9. 막혔을 때
| 화면 | 할 일 |
|---|---|
| 1번 칸에 "양식 미등록" | `TEMPLATE_FILE_ID` 확인. 비워 두면 2번 칸 아래 "양식 pptx 파일" 고르기가 나타남 |
| "이 시트를 볼 수 있는 권한이 없거나 주소가 틀렸습니다" | 보조 본인 계정으로 시트가 열리는지 확인 (시트는 보조 권한으로 읽음) |
| "시트 제목에 데이터 기간이 없습니다" | 시트 제목에 `(09/21-10/25)` 형식 추가 |
| 이미지 받기 실패: Meta API 오류 (190) | 토큰 만료 → 7번 토큰 갱신 |
| 생성 중 "표 열 수가 맞지 않습니다" | 시트 TOP10 표의 지표 열이 바뀜 → 개발 쪽에 알리기 |
| 내려받기가 안 됨 | 크롬 주소창 오른쪽 "다운로드 차단" 아이콘 허용 → 4번 칸의 링크 클릭 |
