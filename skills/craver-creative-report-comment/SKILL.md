# EAST Creative Report 코멘트 초안

생성기가 만든 pptx 의 우수·저조 슬라이드마다 코멘트 박스에 초안을 넣고, 노트에 근거·플래그·콜아웃 후보를 적는다. 실행자는 마케팅 보조(베트남 팀)이고, 초안 검토·수정은 마케터가 한다. 코멘트는 한국어로 쓴다. 보조에게 보내는 안내는 한국어와 베트남어를 함께 쓴다.

## 하지 않는 것
- 제목·KPI·소재명·표·이미지는 바꾸지 않는다. 코멘트 박스와 노트의 '스킬 메모' 칸만 쓴다.
- 콜아웃(빨간 박스)은 그리지 않는다. 문구 후보만 노트에 적는다.
- 숫자를 계산하지 않는다. 문장에 쓰는 숫자는 노트의 시트 값을 그대로 옮긴 것만 쓴다.
- 드라이브의 참고 파일을 고치지 않는다. 학습 반영은 별도 작업이다.

## 순서

### 1. 파일 확인
- 사용자가 첨부한 pptx 를 쓴다. 파일명에서 국가(ID·PH·MY·SG), 유형(OG·PR), 리포트 월(YY-MM)을 읽는다.
- 실행: `python scripts/read_deck.py <pptx> work`
  - `work/deck.json` 에 대상 슬라이드(노트가 '=== 코멘트 근거'로 시작)와 슬롯별 소재명·시트 지표·전월 기록·이미지 경로가 나온다.
  - 대상이 0장이면 멈추고 "생성기 v1.2.0 이상으로 다시 만들어 주세요"라고 알린다.

### 2. 참고 파일 읽기 (드라이브)
`references/sources.md` 의 '코멘트 참고 파일' 폴더에서 아래 순서로 읽는다. 앞의 파일이 뒤의 파일보다 우선한다.
1. `판정결과.md` — 충돌 판정. 국가 파일과 다르면 이것을 따른다.
2. `작성형식.md` — 제목·구조·문체·길이·콜아웃·피해야 할 것.
3. `리뷰어규칙.md` — R1~R9.
4. `성과패턴_{국가}.md` — 국가별 패턴(1장)과 표현(5장)·외부 요인(6장).
5. `성과패턴_공통.md` — 국가 파일에 근거가 없을 때만 보조로.
6. `소재이력_{국가}.md` — 노트에 "전월 자료 없음" 또는 "기록 없음"이 있을 때, 그리고 소재의 이전 코멘트 요지를 볼 때.
7. `변경내역.md` — 마지막 반영 월. 리포트 월 직전 달까지 반영되지 않았으면 요약에 "참고 파일이 {마지막 반영 월} 기준"이라고 적는다.

드라이브 커넥터가 없거나 파일을 못 찾으면 사용자에게 위 파일을 첨부해 달라고 한다. 첨부도 안 되면 멈춘다. 참고 파일 없이 초안을 쓰지 않는다.

### 3. 전월 FN 코멘트 확인 (R3: 전월 문장과 다르게)
- `references/sources.md` 의 FN 위치에서 전월 FN 을 찾는다 (파일명에 `26년 {전월}월`, `FN`, 권역 EAST-1/EAST-2).
- pptx 가 빈 텍스트면 같은 이름의 PDF 를 읽는다.
- 같은 국가·같은 유형·같은 퍼널 슬라이드의 코멘트 문장을 모은다. 초안이 그 문장과 표현이 겹치면 바꾼다.
- 찾지 못하면 각 슬라이드 플래그에 "전월 FN 문장 대조 못 함"을 넣고 계속한다.

### 4. 슬라이드별 초안
각 슬라이드에서 `deck.json` 의 노트와 슬롯 이미지(`work/images/`)를 모두 본다. 이미지가 null 이면 그 슬롯은 이미지 해석 없이 쓰고 플래그 "이미지 없음"을 단다.

**구조**
- 슬롯의 캠페인 라벨이 2개 이상 서로 다르고 국가가 ID·PH 이면 라벨형: `라벨 : 설명` 줄을 라벨마다 하나 (최대 4줄) + ▶.
- 그 밖에는 3줄형: ① 공통 패턴 ② 캠페인 특이점 또는 전월 연속성 ③ 대비 해석(우수 슬라이드는 저조 대비, 저조 슬라이드는 우수 대비, 외부 요인) + ▶ 다음 달 제언.
- 우수<>저조 통합 슬라이드는 ① 우수 ② 연속성·특이점 ③ 저조 + ▶.

**내용 규칙**
- 판단 근거는 이미지에서 보이는 것(첫 화면 구성, 가격·할인 노출, 텍스트 양, 제품 수, 인물, 레이아웃)과 노트의 시트 지표·전월 기록이다.
- 해석 방향은 `판정결과` → `성과패턴_{국가}` → `성과패턴_공통` 순서로 맞춘다. 쓴 패턴 번호는 basis 에 남긴다.
- 이번 달 결과가 패턴과 반대면 숨기지 않는다. "전월과 달리 … 가능성"으로 쓰고 플래그 "기존 패턴과 다름"을 단다.
- 노트에 "N개월 연속" 또는 "전환"이 있으면 1줄 이상 반영한다 (R2).
- 원인은 단정하지 않는다: "~가능성", "~로 사료", "~것으로 판단" (R1).
- 외부 요인(피크데이, 신규 SKU, 예산, 시즌, 피로도)은 노트나 사용자 메모에 근거가 있을 때만 쓴다. 근거가 없으면 "가능성"으로 쓰고 플래그 "근거 약함".
- 판정결과에서 "단정 금지"로 정한 주제(FlashDeal 자체, 세트·번들, 다제품, 피로도)는 조건과 함께 쓴다.
- 문장 안 수치는 1~2개, 노트의 시트 문자열 그대로.
- 국가별 표현: SG 는 "첫 화면" 대신 "한눈에", "전면", "직관성". 국가 파일 5장의 표현을 따른다.
- 개조식 명사형 종결. 본문은 진단형(양상·경향성·확인·판단·사료·가능성), ▶ 는 처방형(필요·제언·의견·제안·검토). 같은 어미 3번 반복 금지. 한 줄 115자 이하.
- 콜아웃 후보: 우수·저조 이유가 이미지에서 바로 보이는 슬롯에만, 6~12자 명사구, 슬라이드당 0~4개.

### 5. 넣기와 점검
1. `work/drafts.json` 작성 (형식은 `scripts/write_comments.py` 맨 위 설명).
   - `flags` 의 type: 근거 약함 / 기존 패턴과 다름 / 이미지 없음 / 전월 FN 문장 대조 못 함 / 확인 필요
2. `python scripts/write_comments.py <pptx> work/drafts.json <출력> --check-only` 로 점검.
   자동 점검 항목(줄 수, ▶, 종결, 단정 표현, 시트에 없는 숫자, 어미 반복, 길이)을 고친다. 최대 2번 고친다.
3. `python scripts/write_comments.py <pptx> work/drafts.json <출력>` 로 저장.
   출력 파일명: 원래 이름 뒤에 `_코멘트초안` (예: `SKIN1004_26-10_EAST_MY_OG_코멘트초안.pptx`).

### 6. 결과 보고
채팅에 아래를 쓰고 출력 pptx 를 첨부한다.
- 슬라이드별 한 줄: 슬라이드 번호, 제목, 플래그 수, 남은 자동 점검 수.
- 마케터가 먼저 볼 줄: "근거 약함", "기존 패턴과 다름" 플래그 목록.
- 참고 파일 기준 월, 전월 FN 대조 여부.
- 보조용 안내 한 줄 (한국어·베트남어):
  "초안이 들어간 파일을 마케터에게 전달해 주세요. 노트 칸의 메모는 지우지 마세요. / Hãy gửi file đã có bản nháp cho marketer. Không xóa ghi chú trong phần Notes."
