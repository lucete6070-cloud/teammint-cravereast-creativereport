# EAST Creative Report 월간 학습 (FN → 참고 파일)

코멘트 초안 스킬(`craver-creative-report-comment`)이 읽는 참고 파일을 매달 FN 기준으로 갱신한다. 사용자는 지윤님. **판정은 지윤님이 한다.** 이 스킬은 후보를 정리하고, 판정이 나온 뒤에만 파일을 올린다.

## 원칙
1. **FN 원문이 기준이다.** 소재명·KPI·코멘트는 원문 그대로 옮기고, 스크립트로 원문 대조를 통과해야 다음 단계로 간다.
2. **사실 기록과 판정을 나눈다.** 소재이력·FN코멘트(사실)는 판정 없이 올려도 되지만, 판정결과(규칙)는 지윤님 답을 받은 뒤에만 바꾼다.
3. **기존 파일은 지우지 않는다.** 드라이브 커넥터는 파일 내용을 고칠 수 없으니, 바뀐 파일은 새로 올리고 옛 파일은 이름 뒤에 `(이전 YYMMDD)` 를 붙인다. YYMMDD 는 그 옛 버전이 만들어진 날 (변경내역 마지막 행 날짜).
4. 성과패턴_*.md 국가 파일은 고치지 않는다. 바뀐 규칙은 판정결과.md 에 넣는다 (판정결과가 우선순위 최상).
5. 광고주 데이터다. 결과는 드라이브 「코멘트 참고 파일」 폴더와 사용자에게만.
6. 사실은 [확인됨]/[추정]/[미확인]으로 구분해 보고한다.

## 위치
- 참고 파일 폴더: 「자동화 TEST/코멘트 참고 파일」 `1gNQ8xfHsJvFpn3N6u3D4C5gjRvggN2Bg`
- 시작할 때 폴더 목록(`parentId = '<폴더 ID>'`)을 한 번 보고 최신 파일을 고른다. 이름에 `(이전` 이 붙은 파일은 지난 버전이니 쓰지 않는다.
- 큰 파일(성과패턴·소재이력 국가 파일)은 커넥터가 파일로 저장한다 → `scripts/read_ref.py` 로 풀어서 필요한 부분만 본다 (`--find 소재명…`, `--ids P-MY-01 …`, `--toc`).
- `<스킬폴더>` 는 이 SKILL.md 가 있는 폴더의 절대 경로.

## 순서

### 1. FN 받기
- 사용자에게 이번 달 FN 위치를 받는다 (드라이브 링크·폴더 또는 업로드). 권역별로 보통 2개: EAST-2(MY·SG), EAST-1/GM3(ID·PH).
- **PDF 를 우선 쓴다** (pptx 는 커넥터가 빈 텍스트를 주거나 10MB 다운로드 한도에 걸리는 경우가 많음).
- 텍스트를 받아 `작업폴더/fn_<권역>.txt` 로 저장한다 (커넥터 결과 그대로 저장해도 됨). 리포트 월(YY-MM)과 데이터 기간은 표지에서 읽는다.

### 2. 코멘트 슬라이드 추출 → extracted.json
코멘트가 있는 콘텐츠 슬라이드만 (표지·간지·TOP10 상세표·BR 제외). PDF 텍스트는 순서가 뒤섞여 있으니 KPI 줄 순서, 캠페인 라벨, TOP10 표의 지출액으로 슬롯과 소재명을 맞춘다. 소재명이 두 줄로 끊긴 것은 이어 붙인다.
```json
{"month": "26-11", "period": "26/10/26 - 26/11/22", "written": "2026-12-03",
 "sources": ["(팀민트) SKIN1004 26년 11월 EAST-2 Creative Report_…_FN.pdf"],
 "slides": [{"country": "MY", "kind": "OG", "funnel": "유입",
             "title": "MY 상시 캠페인 유입 효율 우수 소재 <> 저조 소재",
             "comment": ["본문 1줄", "본문 2줄", "본문 3줄"], "arrow": "▶ 줄 (없으면 빈 문자열)",
             "callouts": ["시간대별 할인 강조"],
             "slots": [{"label": "ATC", "cls": "우수 (장바구니)", "name": "COL-IMG_…_EN",
                        "kpi": "지출 ₩868,905 / 장바구니 CPA ₩295 / ROAS 862%",
                        "gist": "FN 이 이 소재에 대해 말한 요지 (슬라이드 공통이면 '(슬라이드 공통)')"}]}],
 "continuity": [{"item": "MY ALL MASK …", "fn": "3개월 연속 우수"}]}
```
- `cls`: 슬라이드 제목(우수/저조) 또는 슬롯 위 라벨 기준. 통합 슬라이드에서 확실하지 않으면 뒤에 `[추정]`.
- `continuity`: FN 이 "전월에 이어", "N개월 연속", "전월과 달리"라고 쓴 것만.
- 라벨·소재명 불일치, 데이터 기간 밖 이미지 등 이상한 점은 gist 끝에 `[확인 필요: …]`.

### 3. 원문 대조 점검
```bash
python <스킬폴더>/scripts/check_extract.py "<작업폴더>/extracted.json" "<작업폴더>/fn_east2.txt" "<작업폴더>/fn_east1.txt"
```
소재명·KPI 조각·코멘트 줄 앞부분이 원문에 그대로 있는지 본다. **'추출 점검 통과'가 나올 때까지 고친다.**

### 4. 월간 파일 만들기
```bash
python <스킬폴더>/scripts/make_files.py "<작업폴더>/extracted.json" "<작업폴더>/out"
```
→ `소재이력_YY-MM.md`(국가별 표 + 연속성 메모), `FN코멘트_YY-MM.md`(슬라이드별 코멘트 원문 — 다음 달 초안의 R3 점검용)

### 5. 판정 후보 찾기
최신 판정결과 → 해당 국가 성과패턴 → 공통 성과패턴 → 소재이력(국가 파일 + 이전 `소재이력_YY-MM.md`) 순서로 읽고, 이번 달 FN 과 비교한다.
- **반대로 나온 것**: 기존 패턴·판정은 "A면 저조"인데 이번 FN 은 A가 우수 (또는 반대)
- **같은 소재가 뒤집힌 것**: 전월 우수 → 금월 저조 등 (소재이력에서 정확히 같은 소재명)
- **FN 이 새로 말한 규칙**: 기존 파일에 없는 해석이 2개 슬라이드 이상에서 나옴
- **흐름**: 여러 건이 같은 방향이면 메모 (예: "가격·할인 없어도 우수" 4건)
- 코멘트 스킬이 이번 달 만든 초안(노트의 "기존 패턴과 다름" 플래그)이 있으면 함께 본다.

다음 번호를 확인한다:
```bash
python <스킬폴더>/scripts/update_judgments.py next-id "<최신 판정결과 저장본>"
```

### 6. 지윤님께 판정 요청 (여기서 멈춘다)
채팅으로 아래 형식으로 보낸다. 건마다 FN 원문 인용을 꼭 붙인다.
```
**① MY 유입: 할인·판매가 전면 우수 (판정 MY J-02)**
- 11월: (소재·KPI·이미지 특징)
- FN: "(원문 인용)"
- A★ (추천안) / B 기존 유지 / C 기타
```
- 끝에 "참고 (판정 불필요)" 항목과 흐름 메모를 붙이고, "전부 추천대로" 또는 "③은 B, 나머지 추천대로"처럼 답해 달라고 한다.
- 이 단계에서 소재이력·FN코멘트는 먼저 올려도 되는지 묻는다 (사실 기록이라 판정과 무관).

### 7. 판정 반영 (답을 받은 뒤)
1. 이번 달 판정 절을 쓴다 (`작업폴더/section.md`). 제목은 번호 없이 `## YY년 M월 FN 반영 판정 (작성일, 지윤님 판정: …)`. 표 열: `# | 대상 (기존 ID) | M월 근거 | 판정 | 초안 적용`. 단정 금지 주제가 바뀌면 같은 절 안에 "단정 금지 주제 갱신" 표를 넣는다.
2. 새 판정결과 만들기:
   ```bash
   python <스킬폴더>/scripts/update_judgments.py judgments "<최신 판정결과 저장본>" "<작업폴더>/section.md" "<작업폴더>/out/판정결과.md" "YYYY-MM-DD (M월 FN 반영 N건)"
   ```
   새 절은 0장(공통 규칙) 바로 아래, 기존 판정들 위에 들어간다. 지윤님이 공통 규칙 자체를 바꾸면(예: 피로도 허용) 0장 표에 행을 직접 추가한다.
3. 변경내역 행(`작업폴더/rows.md`)을 쓰고:
   ```bash
   python <스킬폴더>/scripts/update_judgments.py changelog "<최신 변경내역 저장본>" "<작업폴더>/rows.md" "<작업폴더>/out/변경내역.md"
   ```

### 8. 드라이브에 올리기
1. 옛 `판정결과.md`, `변경내역.md` 이름을 `판정결과 (이전 YYMMDD).md`, `변경내역 (이전 YYMMDD).md` 로 바꾼다 (파일 메타데이터 수정).
2. `out/` 의 4개 파일을 폴더에 새로 올린다: `판정결과.md`, `변경내역.md`, `소재이력_YY-MM.md`, `FN코멘트_YY-MM.md`. **형식 변환 없이 markdown 그대로** (구글 문서로 바뀌지 않게).
3. 폴더 목록을 다시 보고 새 파일 4개가 있는지, 이전 파일 이름이 바뀌었는지 확인한다.

### 9. 보고
- 올린 파일 4개 링크
- 판정 반영 건수, 소재이력 슬롯 수, [확인 필요] 항목
- 다음 달 코멘트 스킬에 바로 반영된다는 것 (스킬은 폴더 목록에서 최신 파일을 찾음 — 재설치 불필요)

## 하지 않는 것
- 지윤님 답 없이 판정결과 바꾸기
- 성과패턴 국가 파일 수정, 기존 파일 삭제
- 코멘트 초안 작성 (그건 `craver-creative-report-comment`)
