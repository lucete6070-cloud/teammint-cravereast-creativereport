한국어

꼭 지켜 주세요. 시트 CSV, 이미지, 토큰(.env)은 광고주 데이터입니다. 메일·메신저·외부 AI·공유 드라이브에 올리지 마세요. 프로그램 폴더는 C:\creative-report 에 두세요 (OneDrive·바탕화면 안은 안 됩니다).

A. 처음 한 번만 (설치)

1받은 ZIP 을 C:\ 에 풀어 C:\creative-report 폴더가 되게 합니다. (ZIP 을 연 채로 실행하면 안 됩니다. 꼭 "모두 압축 풀기".) 풀기 전에 ZIP 파일을 오른쪽 클릭 → 속성 → 아래 "차단 해제" 체크 → 확인. (안 하면 Windows 가 .bat 파일을 막을 수 있습니다.)
2Python 설치: python.org → Downloads → 설치 파일 실행. 첫 화면 아래의 "Add python.exe to PATH" 에 체크하고 Install. 질문이 나오면 대부분 y/Y (이미 설치돼 있으면 건너뜁니다).
3setup.bat 을 더블클릭합니다. 검은 창에서 부품이 설치되고, 마지막에 메모장(.env)이 열립니다. 지윤님께 받은 값을 = 바로 뒤에 붙여넣고 Ctrl+S 로 저장한 뒤 닫습니다. 
META_ACCESS_TOKEN=받은토큰
META_AD_ACCOUNT_ID_MY=말레이시아계정ID
META_AD_ACCOUNT_ID_SG=싱가포르계정ID
META_TOKEN_ISSUED=토큰발급일(예: 2026-10-15)
띄어쓰기·따옴표 없이 한 줄로 붙입니다. 토큰은 다른 사람에게 보여 주거나 캡처하지 마세요.
4끝에 "점검 결과: 문제 없음" 이 보이면 준비 끝. 오류 문구가 있으면 그 내용대로 고치세요.

B. 매달 하는 일

더 쉬운 방법: 웹 화면. start_app.bat 을 더블클릭하면 브라우저에 화면이 열립니다 (검은 창은 닫지 마세요). 화면에서 ① 연결 확인(토큰·계정도 여기서 입력) ② CSV 끌어다 놓기 ③ 담당 국가 체크 후 [생성하기] ④ 결과 내려받기 순서로 하면 됩니다. 아래 1~6번은 같은 일을 run_all.bat 로 하는 방법입니다.
1시트 확정: 마케터가 고효율/저효율 체크박스를 확정했는지 확인합니다.
2CSV 내려받기: 시트의 국가 탭마다 파일 → 다운로드 → 쉼표로 구분된 값(.csv). 국가·유형별로 MY_OG&TEST, MY_PR&BR, SG_OG&TEST, SG_PR&BR 4개입니다. (엑셀로 내려받으면 수식이 깨지니 꼭 CSV.) 파일 이름에 (08_24-09_20) 같은 데이터 기간이 들어 있어야 합니다. 시트 이름 그대로 내려받으면 자동으로 들어갑니다.
3input 폴더의 지난달 파일을 모두 지우고 이번 달 CSV 만 넣습니다.
4run_all.bat 을 더블클릭합니다. 점검 → Meta 이미지 받기 → pptx/HTML 만들기 순서로 자동 진행됩니다 (몇 분).
5끝나면 output 폴더가 자동으로 열립니다. 국가×유형별 pptx(편집용)와 html(보기용)이 생깁니다. pptx 를 열어 이미지·숫자를 훑어본 뒤 마케터에게 전달하세요. 코멘트 칸은 비어 있는 것이 정상입니다.
6화면에 [주의] 나 실패 가 있으면 output 의 실행기록_*.txt 를 지윤님께 보내 주세요 (토큰은 기록에 남지 않습니다).

C. 이미지를 직접 바꾸고 싶을 때

이미지 파일 이름은 소재명.png 입니다. 바꿀 이미지를 같은 이름으로 images_manual 폴더에 넣으면 그것이 우선 쓰이고, 자동 수집이 덮어쓰지 않습니다. (images 폴더는 실행할 때마다 새로 받습니다.)

Tiếng Việt

Bản dịch nháp — nhờ đồng nghiệp người Việt kiểm tra lại câu chữ.

Rất quan trọng. File CSV từ Sheet, hình ảnh và token (.env) là dữ liệu của nhà quảng cáo. Không gửi qua email, ứng dụng nhắn tin, AI bên ngoài hoặc ổ đĩa dùng chung. Đặt thư mục chương trình tại C:\creative-report (không để trong OneDrive hoặc Desktop).

A. Chỉ làm một lần (cài đặt)

1Giải nén file ZIP vào C:\ để có thư mục C:\creative-report. (Không chạy khi đang mở bên trong ZIP; hãy chọn "Extract All".) Trước khi giải nén: bấm chuột phải vào file ZIP → Properties → tick "Unblock" ở phía dưới → OK. (Nếu không, Windows có thể chặn file .bat.)
2Cài Python: vào python.org → Downloads → chạy file cài đặt. Ở màn hình đầu tiên, tick vào "Add python.exe to PATH" rồi bấm Install. Nếu có câu hỏi, thường chọn y/Y (nếu đã cài rồi thì bỏ qua).
3Nhấp đúp setup.bat. Cửa sổ đen sẽ cài thư viện, cuối cùng mở Notepad (.env). Dán các giá trị nhận từ Jiyoon ngay sau dấu =, bấm Ctrl+S để lưu rồi đóng. 
META_ACCESS_TOKEN=token_nhận_được
META_AD_ACCOUNT_ID_MY=ID_tài_khoản_Malaysia
META_AD_ACCOUNT_ID_SG=ID_tài_khoản_Singapore
META_TOKEN_ISSUED=ngày_phát_hành_token (ví dụ: 2026-10-15)
Dán trên một dòng, không có khoảng trắng và dấu ngoặc kép. Không cho ai xem hoặc chụp màn hình token.
4Khi thấy "Kết quả: không có vấn đề" ở cuối là đã sẵn sàng. Nếu có thông báo lỗi, hãy sửa theo nội dung đó.

B. Việc làm hàng tháng

Cách dễ hơn: màn hình web. Nhấp đúp start_app.bat thì trình duyệt sẽ mở màn hình (đừng đóng cửa sổ đen). Trên màn hình: ① Kiểm tra kết nối (cũng nhập token/tài khoản tại đây) ② Kéo thả CSV ③ Tick quốc gia phụ trách rồi bấm [Tạo file] ④ Tải kết quả. Các bước 1~6 bên dưới là cách làm cùng việc đó bằng run_all.bat.
1Chốt Sheet: xác nhận marketer đã chốt các ô đánh dấu hiệu quả cao/thấp.
2Tải CSV: ở mỗi tab quốc gia chọn File → Download → Comma-separated values (.csv). Có 4 file: MY_OG&TEST, MY_PR&BR, SG_OG&TEST, SG_PR&BR. (Không tải dạng Excel vì công thức sẽ bị lỗi, phải dùng CSV.) Tên file phải có khoảng thời gian dữ liệu như (08_24-09_20); nếu tải đúng tên Sheet thì sẽ có sẵn.
3Trong thư mục input, xóa hết file của tháng trước và chỉ để CSV của tháng này.
4Nhấp đúp run_all.bat. Chương trình tự chạy: kiểm tra → tải ảnh từ Meta → tạo pptx/HTML (vài phút).
5Khi xong, thư mục output tự mở. Mỗi quốc gia × loại có file pptx (để chỉnh sửa) và html (để xem). Mở pptx kiểm tra nhanh ảnh và số liệu rồi gửi cho marketer. Các ô comment để trống là bình thường.
6Nếu màn hình có [LƯU Ý] hoặc thất bại, hãy gửi file 실행기록_*.txt trong output cho Jiyoon (token không được ghi vào file này).

C. Muốn tự thay ảnh

Tên file ảnh là tên creative.png. Bỏ ảnh cần thay vào thư mục images_manual với đúng tên đó thì ảnh này được ưu tiên và không bị tải tự động ghi đè. (Thư mục images được tải mới mỗi lần chạy.)
